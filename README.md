# das Wort

Немецкий ↔ русский. Нативное приложение для Mac. Автор: **Maxim S.**

[Скачать последнюю версию](https://github.com/Syrmus/das-wort-releases/releases/latest)

Для Mac с Apple Silicon, macOS 14+. Скачайте ZIP без суффикса `-local`, распакуйте и перенесите приложение в «Программы». При первом запуске войдите в свой аккаунт ChatGPT.

Приложение проверяет обновления раз в день. Проверить вручную: **das Wort → Проверить обновления…**. Установка требует подтверждения. Подписи списка версий и архивов проверяются через Sparkle / Ed25519.

Тестовая сборка без нотариального заверения Apple: [инструкция Apple по первому запуску](https://support.apple.com/102445).

Здесь публикуются только готовые сборки и файлы обновлений. Исходный код, личные настройки и данные аккаунтов не входят в релизы.
